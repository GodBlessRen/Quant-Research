# 市场状态、拥挤与压力

> **研究者独立增补** · 对照原书第12、13、15、16课。这是一套判断“市场脆弱程度”的研究框架，不是自动择时信号。

## 1. 为什么一个“风险分数”往往不够

涨幅、成交量、波动率、估值、相关性可以同时走高，但它们描述的不是同一种现象。

建议区分：

```
MarketState = (T, C, S, V)

T — Trend Quality：趋势质量
C — Crowding：交易拥挤与共同退出风险
S — Stress：市场压力与流动性恶化
V — Valuation：估值脆弱性
```

T 高可能意味着健康趋势，也可能意味着仅少数龙头推动指数上涨；C 高意味着共同交易/共同退出路径拥挤，但不说明何时下跌。S 低不等于市场安全；V 高不是顶部日期的计算器。

**不要把这四维指标随意加权成一个“75分风险值”**。没有解释性和样本外校准的权重只会创造伪精度。

## 2. 拥挤 C 与压力 S：最重要的区分

| | 压力低 S↓ | 压力高 S↑ |
| --- | --- | --- |
| **拥挤低 C↓** | 相对健康，但仍可能突然遇到外部冲击 | 可能是外生事件或拥挤释放后段 |
| **拥挤高 C↑** | **脆弱的平静**：风险可能被低波动掩盖 | **共同去杠杆**：集体被迫减仓 |

其中“高 C、低 S”值得特别观察：资金可能继续推高价格、IV 仍然很低、市场新闻依然乐观，但持仓路径更集中、退出流动性却没有同比增长。注意这不是马上暴跌的充分条件。

## 3. 相关性为何让分散化失效

一般组合方差：

$$
\sigma_p^2 = \sum_i w_i^2\sigma_i^2 + 2\sum_{i<j}w_i w_j\rho_{ij}\sigma_i\sigma_j
$$

当 N 个资产等权、波动相同、两两相关为同一个 ρ：

$$
\sigma_p^2 = \sigma^2\left[\rho+\frac{1-\rho}{N}\right]
$$

等权持有10只年化波动20%的资产，若相关性从0.1上升到0.9，组合风险会显著接近单资产风险。右侧原实验室可用滑块观察这条数学关系。

**重要限制**：相关性增加不是凭空创造额外风险，而是使原本预期的分散效果下降。更不能从“相关性高”直接推出价格明天会下跌。上涨同步也会令相关性上升。

## 4. 如何量化 Crowding（拥挤）

至少从三条相对独立的路径观察：

1. **横截面结构**：成分股平均相关、PCA 第一主成分解释率、权重 HHI、指数上涨由多少股票贡献；
2. **资金与仓位**：ETF 净流入、杠杆/融资代理、期权 OI 集中度、相似风格基金持仓；
3. **退出条件**：买卖价差、盘口深度、订单占 ADV、成交冲击、压力期相关性跃升。

不应把价格涨幅直接等同于拥挤：趋势可以持续很久；一个相对冷门且流动性不足的品种，也可能在没有大涨时出现严重拥挤。

## 5. 波动率要看曲面，而非单个 IV

至少区分：

- **IV Rank / Percentile**：当前 IV 相对于自身历史的水平；
- **IV − RV**：隐含波动率与同期已实现波动率差；
- **Put Skew**：同期限、可比 moneyness 的下行保护溢价；
- **Term Structure**：短端、中端、长端对风险事件的定价。

如果现货仍强、广度下降、Put Skew 升高、短端 IV 上行，并且高杠杆仓位没有出清，这个组合比“IV 高”本身更有信息量；但财报季、事件风险、做市商仓位和期权供需仍是可能的替代解释。

## 6. 对 Regime 模型的校勘

使用如下固定规则作为教学基线是可以的：

```python
if annual_volatility > 0.30:
    regime = "high_volatility"
```

但是：

- 某些小盘指数的正常波动可能远高于大盘蓝筹；
- 相同绝对波动率阈值不能自然迁移到股票、债券、加密资产；
- 机器学习模型产生的概率未经校准，不能直接解释为真实命中率；
- 模型“正确识别市场状态”的准确率也不等于可获得净收益。

更可信的方法：使用自身历史分位、同类资产条件分布、滚动样本外测试，以及概率校准曲线 / Brier Score；另外统计状态切换后的平均交易成本与真实收益。

## 7. 状态到交易动作仍须经过门禁

| 场景 | 需要的新证据 | 研究行动 |
| --- | --- | --- |
| 趋势健康，拥挤低，压力低 | 市场广度和盈利修正继续改善 | 尊重趋势，不预测顶部 |
| 趋势仍强，拥挤上升，压力低 | 资金集中与流动性是否背离 | 降低新增敞口的激进度 |
| 拥挤高，压力开始抬升 | Skew/短 IV/广度与实际强制卖盘 | 评估对冲或降低相关风险 |
| 高拥挤高压力 | 融资出清、成交成本、市场深度 | 优先生存，谨慎处理流动性 |
| 压力缓解且拥挤下降 | 价格不再创新低、广度复苏 | 允许预设预算内试错 |

最后保留失效条件：一旦数据无法支持当前状态估计，输出**未知**，不要用固定规则硬凑结论。

> 趋势决定方向；相关性决定脆弱度；波动率决定风险的价格；仓位决定能否活到下一轮。
