# 证据优先：量化研究的方法论

> 这是一篇 **Quant Research 独立编写的研究补充**，不是原作者 Wayland Zhang 的原文。它说明如何从教材中的方法走向可复核、可证伪的研究实践。

## 1. 一个策略应当回答的六个问题

一个声称有效的量化策略，至少需要说明：

1. **机制（Mechanism）**：究竟利用了什么市场行为或约束？为什么不应立即被竞争者套利消除？
2. **信息（Information）**：信号所依赖的信息何时公开、何时可取得、何时能够成交？
3. **检验（Evidence）**：表现是否来自真正封存的样本外数据？试验次数是否记录？
4. **实现（Implementation）**：是否计算点差、费用、冲击、延迟、成交率和容量？
5. **失效（Invalidation）**：怎样的结果说明假设不成立、必须停止或降级？
6. **复核（Review）**：触发复查的是新数据、参数漂移、外部制度变化，还是到了预先指定的日期？

如果回答只有“夏普不错，回测曲线很平滑”，它最多是一个探索性发现。

## 2. 事实、解释与行动必须分层

| 层次 | 示例 | 合格要求 |
| --- | --- | --- |
| 事实 | 某类资产过去 60 日平均相关性上升 | 给出样本池、日期、定义和代码 |
| 解释 | 可能存在共同因子暴露或交易拥挤 | 同时列出替代解释 |
| 行动 | 降低新增风险敞口，等待广度修复 | 说明触发条件、风险预算和失效条件 |

相关性升高 **不是** 股市马上崩盘的定时器。同样，PE 高、ETF 净流入、换手率高都不能单独决定买卖。

研究中要刻意寻找竞争解释：相关性上升可能是宏观冲击，也可能是指数成分变更；高收益可能是幸运的参数筛选，也可能是未建模的空头风险。竞争解释并不会减弱研究，反而帮助寻找决定性的验证实验。

## 3. 研究合约（Research Contract）

在接触样本外表现前，为每一个假设创建可追溯记录。

```yaml
research_id: QR-0001
question: "信号是否在扣除交易成本后拥有稳定预测力？"
universe: "当期真实可投资股票池，包含退市证券"
decision_timestamp: "交易所收盘后信息完整可得的时点"
data_version: "供应商 + 数据快照哈希 + 调整与清洗版本"
features: ["只使用当时可得的价格、财报与事件"]
label: "未来5个交易日扣费前收益"
label_end_time: "每个样本真实结束时刻"
train_split: "事先冻结的滚动时间窗口"
validation: "walk-forward + 对重叠标签做 purge"
holdout: "封存测试区间，不重复用来调参"
benchmark: "相同投资池、延迟和成本口径的基准"
search_budget: "记录所有已尝试模型、参数、因子"
risk: "最大仓位、行业与杠杆、净敞口约束"
cost: "费用、价差、滑点、冲击与容量"
pass_gate: "净收益、风险、稳健性和置信区间"
invalidation: "预先定义的失效证据或风险阈值"
owner: "研究责任人"
```

它的作用不在于格式，而在于**阻止测试完成后才重新定义成功条件**。

## 4. 从发现到上线的五道证据门

### Gate A：数据门

复原当时可见信息集；核查发布时间、退市、停牌、复权、时间对齐、样本池重构与缺失机制。无法明确时间戳，研究不能进入严格回测。

### Gate B：统计门

用简单基线对照。报告样本外表现、估计不确定性、参数稳定性、试验次数；收益为非正态且重复测试时，不要把传统 Sharpe t 检验当作唯一证据。必要时使用 DSR、PBO、区块自助法和合适的依赖稳健统计。

### Gate C：经济门

判断收益来自风险溢价、信息优势、行为约束、流动性提供还是技术性补偿。若只在某一种事后挑选的市场阶段有正收益，需检验是否存在选择偏差。

### Gate D：执行门

真实报价、成交概率、点差、费用、冲击、队列、订单拒绝与延迟进入模拟器。高换手策略必须做成本和容量敏感性分析。

### Gate E：运行门

实盘前先影子运行；风控、超时、断线、重复成交、未知结果和持仓对账都应有确定性恢复规则。**成功发送订单不等于已经成交**。

## 5. 不要盲目合成一个“风险总分”

推荐保留两个相互补充的状态向量。

微观市场风险：

```
MarketState = (T, C, S, V)
T = 趋势质量    C = 拥挤度
S = 市场压力    V = 估值脆弱性
```

宏观资产负债表：

```
MacroState = (B, F, M, C, L, N)
B = 债务负担   F = 财政冲量    M = 货币立场
C = 私人信用   L = 流动性      N = 名义增长
```

缺失值就是“未知”，不要伪造 0—100 分精度。两种状态模型面向不同问题，不能混合解释成一个必然涨跌的信号。

## 6. 最小研究结论模板

每一份研究报告最后都应保留下面六行：

| 字段 | 应填写的内容 |
| --- | --- |
| State | 当前市场/策略状态，注明日期 |
| Evidence | 至少三类独立或低相关的证据 |
| Trigger | 哪种可观测变化值得行动 |
| Action | 观望、试仓、降风险、对冲或退出 |
| Invalidation | 什么事实足以推翻判断 |
| Review | 下一次检查的时间或触发事件 |

禁止在没有明确风险预算和执行约束的情况下，虚构具体仓位比例。**“暂不交易”是完全有效的研究结论。**

## 7. 研究系统的最终任务

追求更高的收益不是工程上唯一的目标。一个可依赖的研究系统还必须：

- 知道结论依赖哪些数据与假设；
- 能区分“还没有证据”与“证据显示失败”；
- 在重试、断线、对账中保留真实状态；
- 在证据不足时拒绝从研究阶段升到实盘阶段；
- 允许独立团队依据相同数据版本复现实验。

> 研究可以大胆；证据必须保守。
