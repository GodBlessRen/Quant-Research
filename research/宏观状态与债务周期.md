# 宏观状态与债务周期：中美研究不应只靠类比

> **Quant Research 独立撰写** · 这篇专题是教材之外的扩展阅读，集中处理债务置换、财政冲量、TGA、美国国债回购与资产定价的可证伪机制。

## 1. 先分清债务管理、财政刺激与货币宽松

同样叫“化债”，不同制度下的资金流、风险承担和受益主体可能完全不同。

| 操作 | 直接改变什么 | 不保证产生什么 |
| --- | --- | --- |
| 债务展期/置换 | 利率、期限、持有人、滚续压力 | 新的净需求和经济增长 |
| 国债回购 | 未偿证券构成、流动性与期限分布 | 净债务必然下降 |
| 财政刺激 | 政府支出、转移支付与净需求 | 私人部门信用自然跟随 |
| 央行 QE | 准备金与央行资产持有，常涉及久期吸收 | 所有风险资产必然上涨 |

美国财政部买回旧券与联储 QE 的会计主体不同；美国国债回购可以通过发行新债筹资，因此不等于净债务减少。中国地方债置换降低利息负担，也不意味着私人投资会立即恢复。

## 2. 六维宏观状态

```
MacroState = (B, F, M, C, L, N)

B: Balance-sheet burden  债务负担与偿债约束
F: Fiscal impulse        财政冲量，是否创造新的总需求
M: Monetary stance       货币立场、久期吸收与真实利率
C: Private credit        私人部门信用的价格与数量
L: Liquidity             货币市场与二级市场流动性
N: Nominal growth        名义收入、利润与税收验证
```

债务风险减轻（B改善）可以是积极的金融稳定信号，但若 F、C、N 没有跟随，很难直接证明经济已经进入再通胀扩张。

## 3. 中国：地方债务修复到私人信用

可检验的路径：

```
高成本/短久期的存量负债
       ↓ 债务置换、期限延长
利息与到期支付压力下降
       ↓ 是否真实传递？
地方支出与拖欠款改善
       ↓ 是否真实传递？
企业现金流、信贷需求改善
       ↓ 是否真实传递？
投资、名义收入、盈利预期上修
```

重点跟踪：地方债发行用途、财政支出、应付款项、社融结构、中长期企业贷款、M1、房地产销售、PPI与GDP平减指数、民间投资、盈利上修。

注意：“金融风险减少”与“股票估值应大涨”之间有多个尚待验证的传导环节。

## 4. 美国：Treasury、TGA 与金融市场久期供需

TGA 是财政部在联储的现金账户。其下降在其他条件不变时通常对应银行准备金增加；TGA 回补在其他条件不变时通常压低准备金，但实际传导仍受国债发行、逆回购、货币市场基金和央行操作共同影响。

研究“回购将推高股市”需要同时回答：

1. 回购是否由财政部正式公布？期限篮子、上限与实际成交是多少？
2. 资金来自 TGA 余额、当期融资还是新券发行？
3. 哪类券被买回？对利率期限结构与做市商库存有何变化？
4. 是否观察到市场深度、价差、回购利率与期限溢价的真实改善？
5. 改善是否传至公司债 OAS、融资发行、资本开支与盈利预期？

**大额现金余额不是可以任意动用的“回购战争基金”证据。** 口径必须以财政部与联储正式数据为准，不能用市场传言替代计划公告。

## 5. 美股下跌的竞争解释

美国成长股下跌可能来自多个不同的跨资产冲击；不要在下跌后只挑一个符合原有叙事的理由。

| 假设 | 更应出现的可观察信号 |
| --- | --- |
| 期限溢价/财政供给冲击 | 长端收益率上行、曲线熊陡、长久期资产相对弱 |
| 通胀冲击 | 名义利率和通胀补偿同步变化 |
| 实际利率/货币收紧 | 实际利率上行，成长股估值承压 |
| 增长冲击 | 收益率下行，周期股与小盘走弱，信用利差走阔 |
| 信用冲击 | OAS/CDS 上行、一级发行溢价扩大 |
| 流动性去杠杆 | 波动率和相关性跃升、市场深度下降、回购/基差异常 |

真正强的宏观研究不是讲一个故事，而是预测：**如果故事为真，其他市场应该同时出现什么？**

## 6. 从宏观状态映射到量化资产

- **成长股/科技资产**：区分盈利增速、实际利率、股权风险溢价和资本开支自由现金流；
- **银行和小盘股**：观察贷款数量、信用成本、存贷款利差、再融资依赖；
- **国债**：短端以政策预期为主，长端还要看期限溢价、供给和流动性；
- **信用债**：相同久期国债收益率与 OAS 分开；绝对票息高不等于信用风险高；
- **黄金和储备资产**：研究真实利率、货币可信度和尾部风险，而非单句“印钱”。

## 7. 最后把观点变成可证伪的假设

```
事实：    已公开的政策工具、发生时间、数额和期限
机制：    哪个资产负债表发生了怎样的存量/流量变化
传导：    对准备金/利率/融资条件/利润的路径
替代：    至少两条竞争解释
证据：    至少三类独立指标与各自的数据日期
触发：    哪种新信息会改变当前判断
失效：    哪个事实足以推翻宏观叙事
行动：    考虑仓位、执行成本和尾部风险后是否值得交易
```

> 对宏观研究而言，真正重要的不是谁在“化债”，而是谁的资产负债表改变了、通过什么渠道、是否最终转化为现金流和价格。
