# 回测、标签与时间序列验证

> **研究者独立校勘** · 对照原书第06、07课。目标是把“不要使用未来数据”从一句口号变成可编码、可测试的不变量。

## 1. 区分三个时钟

历史数据往往包含三个不同的时间字段：

- `event_time`：经济事件/市场成交真实发生时间；
- `published_at`：信息被对外披露的时间；
- `available_at`：数据通过指定供应商和处理流水线真实可供策略使用的时间。

对于决策时刻 `t`，能用于特征的样本必须满足：

```
available_at <= t
```

财报可能属于第一季度，却在第二季度末发布；历史供应商可能会用更新后的财报覆盖当期初版。这些事实意味着“报告期小于回测日期”并不能证明策略当时知道这些数据。

当数据来自不同频率，还要注意：股票收盘价、期货结算价、财务公告与美股盘后披露并不共享一个“交易日结束”的时钟。

## 2. 未来标签与未来特征不是一回事

预测未来五日收益的典型监督学习任务：

$$
X_t = \text{截至 }t\text{ 可得的全部特征}
$$

$$
y_t = \frac{P_{t+5}}{P_t}-1
$$

**在历史样本训练中，使用 `y_t` 并没有天然的前瞻偏差。** 重要的是：在时间点 `t` 做交易决策时，不能提前知道 `y_t`；在回测时间点训练模型时，不能使用标签结束时间晚于训练截止日的样本。

错误情况：

```python
# 今日特征中偷放“未来五日收益”
features["future_return"] = price.shift(-5) / price - 1
```

允许的标签定义：

```python
# 标签是研究者在事后形成的监督目标
labels = price.shift(-5) / price - 1
# 但模型训练必须控制该标签的实际实现时点。
```

另一种常见错误是先用全样本均值标准化，再按时间分训练/验证集。标准化器必须只在训练窗口拟合，再用于其后的验证/测试。

## 3. Purging 与 Embargo 不应教条化

当标签持有区间彼此重叠，例如事件样本 `i` 使用未来区间 `[t_i, t_i+5]`，把某一天当作训练/验证的硬边界仍可能泄漏跨边界的结局信息。

- **Purging**：删除训练集中标签信息区间与验证区间发生重叠的样本。
- **Embargo**：在必要时额外隔离验证区间附近的训练观测，以削弱标签、特征计算窗口或市场微结构造成的依赖。

真正决定隔离长度的是**标签实际结束时间及相关依赖结构**，而不是“统一空出五天”这样的万能口诀。不同资产、交易日历和事件驱动标签可能持有期不等长。

## 4. 时间序列验证：一个可审计方案

```
训练窗口 A ───▶ 验证窗口 B
                     │
                     └── 锁定模型/成本/阈值
                                   │
                            封存测试窗口 C
```

Walk-forward（滚动向前）可以重复 A→B 的训练与验证，但最终确认性测试区间不应反复用于调参。

示例：训练集的平均值不得使用验证集数据：

```python
import numpy as np

def zscore_from_train(train: np.ndarray, test: np.ndarray):
    mu = np.mean(train, axis=0)
    sigma = np.std(train, axis=0)
    sigma = np.where(sigma == 0, 1.0, sigma)
    return (train - mu) / sigma, (test - mu) / sigma

train = np.array([[1.0], [2.0], [3.0]])
test  = np.array([[4.0]])
a, b = zscore_from_train(train, test)
assert round(float(b[0, 0]), 6) == round((4.0 - 2.0) / np.std(train), 6)
```

它仅展示标准化“只在训练集拟合”的不变量；实际回测还需切分日期、实现持有期、公司行动及交易日历。

## 5. 回测引擎还应通过什么测试？

| 不变量 | 要验证的反例 |
| --- | --- |
| 订单只能依赖已可得信息 | 用 T 日收盘后才生成的信号，回测却以同日开盘价成交 |
| 真实投资池 | 只剩当前仍上市的股票，忽略历史退市与除牌 |
| 成本与成交时序 | 按下一期开盘价假设全额成交、没有排队和停牌 |
| 训练/测试隔离 | 用测试集表现选择最优参数后再宣布它是样本外 |
| 试验完整记录 | 测试200组参数，却只报告胜出的一个 |
| 基准公平 | 基准不计算费用，策略却用了不同调仓频率或杠杆 |

**“取下一期开盘价”也不是自动证明可交易**：要考虑开盘集合竞价、买卖限制、流动性、涨跌停、订单到达延迟与真实可成交数量。

## 6. 推荐同时报告四个结果

1. **原始回测**：明确理想化假设，作为研究上界，不声称可兑现。
2. **成本化回测**：费用、点差、滑点、冲击和容量压力进入。
3. **稳健性检验**：多窗口、多子市场、参数邻域、交易延迟扰动。
4. **影子运行**：实际接收行情与模拟发单，检查软件事件时钟是否与回测一致。

### 对原书的具体校勘

原书关于“未来收益用于标签”的风险提示，需要额外补上**特征与监督标签的区分**。未来标签本身并非错误，错误来自信息时间线不受约束。

真实研究还应把 **样本外确认** 与 **上线可交易性** 分开验收。算法证明模型的历史统计性质，不代表订单一定能够在历史价格成交。
